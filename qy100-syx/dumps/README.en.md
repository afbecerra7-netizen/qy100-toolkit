# Reference dumps

> **English translation of [`README.md`](README.md).** Keep the two in sync — this
> file is not authoritative; if they disagree, the Spanish original wins.

The eight files here are reverse-engineering artifacts, not music: each
contains **a single note** recorded on the device with one parameter changed
at a time — pitch, velocity, position, duration. They are the evidence
`test_protocol.py` checks the decoder against, which is why they're included.

Without them the suite runs 84 checks instead of 117.

The rest of the project's working dumps are not here: they aren't needed to
use the tools, and some contain unreleased music.
