# Volcados de referencia

Los ocho archivos aquí son artefactos de ingeniería inversa, no música: cada uno
contiene **una sola nota** grabada en el equipo con un parámetro cambiado a la
vez — altura, velocity, posición, duración. Son la evidencia contra la que
`test_protocol.py` comprueba el decodificador, y por eso se incluyen.

Sin ellos la suite corre 84 comprobaciones en vez de 117.

El resto de volcados del trabajo no está aquí: no hacen falta para usar las
herramientas y algunos contienen música inédita.
