# QY100 Part — a Max for Live device for the QY100

**QY100 Part** controls one part of the QY100's tone generator from an Ableton
Live MIDI track: pick the voice by name, shape it with ten knobs, and set the
reverb, chorus and variation types. It sends nothing but standard MIDI and XG
messages, so the QY100 needs no special setup beyond receiving MIDI.

The ready-made device is `QY100 Part.amxd`, in [`qy100-syx/max/`](../qy100-syx/max/).
It is generated by [`qy100-syx/herramientas/m4l_qy100.py`](../qy100-syx/herramientas/m4l_qy100.py),
which needs nothing beyond Python's standard library:

```bash
cd qy100-syx && python3 herramientas/m4l_qy100.py --salida "QY100 Part.amxd"
```

## What it does

| Block | Controls | What it sends |
| --- | --- | --- |
| **Voice** | Family (the 16 GM families, SFX, drum kits) and voice, 530 in all, by name | Bank Select MSB (CC 0), LSB (CC 32) and Program Change |
| **Mix** | Volume, Pan, Expression | CC 7, 10, 11 |
| **Tone** | Brightness, Resonance, Attack, Release | CC 74, 71, 73, 72 |
| **Sends** | Reverb, Chorus, Variation | CC 91, 93, 94 |
| **Effects** | Reverb type (12), chorus type (12), variation type (44) | XG Parameter Change `F0 43 10 4C 02 01 <00/20/40> MSB LSB F7` |

The voice and bank numbers come from the QY100 Data List (pp. 2–3), and 508 of
the names were checked against the firmware ROM; the effect type lists come
from its Effect Type List. CC 94 only matters while the variation effect is
connected as a system effect, which the Data List notes.

- **Choosing a family already changes the sound**, to the first voice of that
  family; then pick the voice you want.
- **The voice is saved with the Live Set** as a parameter (`Voice`), can be
  automated, and is sent again when the set opens.
- **Effect types are global on the QY100**, not per part. They are only sent
  from the copy of the device whose **GLOBAL** button is on — turn it on in
  one track only. That copy also tells the others, whose menus then show the
  same types without sending anything.
- Incoming notes pass through untouched.

## How to use it

1. Put a MIDI track in Live whose MIDI goes to the QY100 on the part's
   channel. An **External Instrument** works well: set its *MIDI To* to the
   interface and channel that reach the QY100.
2. Drop **QY100 Part** on the track **before** the External Instrument. The
   device sends on channel 1 and the External Instrument re-channels it.
3. One track per part: duplicate the track and change the channel. Each copy
   controls its own part.

Measured with a QY100 on 2026-11-22 `[M]`, Live 12.4.16 on macOS, MIDI reaching
the QY100's MIDI IN through a USB–MIDI interface:

- Program Change and Bank Select change the part's voice; the numbering is GM
  counted from 0 (program 0 piano, 40 violin, 73 flute).
- With one track per channel, each part's voice and reverb and chorus sends
  change without touching the others.
- The reverb type changes by SysEx, also when sent from the device — Live
  passes SysEx from a Max device through the track and the External
  Instrument.
- In **pattern mode** the QY100's front panel fixes the reverb to HALL1 and the
  chorus to CHORUS1 (owner's manual, p. 122), but **over MIDI the type does
  change**.

Two things to check if nothing happens:

- `HOST SELECT` on the back of the QY100 must be on `MIDI`, or it ignores the
  MIDI IN socket.
- The XG messages use device number 1 (`F0 43 10 …`), the QY100's default `[D]`.

## QY100 Silence — keep the QY100 off the channels of other synths

When the QY100's MIDI IN feeds a whole rig, with `ECHO BACK = Thru`, a note
meant for an external synth also plays the QY100 part on that channel. **QY100
Silence** stops that: sixteen channel buttons, a **SEND** and a **RESTORE ALL**.
It is `QY100 Silence.amxd` in the same folder, generated by
[`m4l_qy100_silencio.py`](../qy100-syx/herramientas/m4l_qy100_silencio.py).

- A lit button means the QY100 ignores that channel. **SEND** sends all sixteen:
  lit channels get `Rcv Channel = Off` (`F0 43 10 4C 08 <part> 04 7F F7`), unlit
  ones go back to their own channel. Pressing a button sends nothing by itself.
- **RESTORE ALL** puts every part back on its own channel, without touching the
  buttons.
- The buttons are saved with the Live Set. The defaults (1, 3, 4, 5, 6) and the
  labels under 1–8 are one particular rig's; change `CALLADOS` and `NOMBRES` in
  the generator for yours.

Measured on 2026-11-22 `[M]`:

- **Lowering the part's volume is not a substitute.** The QY100 passes the
  change on, and a synth that reads CC 7 as its level gets quieter too.
- **`Rcv Channel = Off` does not survive a power cycle.** Press SEND at the start
  of each session; switching the QY100 off and on is the way back to it playing
  alone.
- Sent from the device in Live, through the track and an External Instrument,
  the synths played alone afterwards.

`[D]` Part *n* receives channel *n* + 1, the XG default. With the part ignoring
the channel, it ignores that channel's control changes too, not only its notes.

## Requirements

Ableton Live with Max for Live. The logic runs in a `v8.codebox` (JavaScript
inside the patch), which needs **Max 9** — tested with the Max 9.1.5 bundled in
Live 12.4.16. Earlier versions of Live, with Max 8, will not load it `[D]`.
